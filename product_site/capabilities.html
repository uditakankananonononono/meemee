CAPABILITY LEDGER

What works. What does not.

This page describes shipped behavior, not roadmap promises.

Available now

Customer product

Email/password signup and login, onboarding, web chat, conversation history, persona editing and account-owned API keys.

Companion

Provenanced fact memory, source/confidence history, persona-conditioned replies, check-in scheduling with quiet hours and local delivery.

Agent runtime

Bounded plans, typed tools, approvals, safe browser and file operations, live human takeover when a site shows a challenge, jobs, retries, cancellation and inspectable audit history.

Operations

SQLite single-host production shape, optional PostgreSQL components, backups, retention, readiness, metrics, Docker and Kubernetes assets.

Access

Revocable scoped tokens, built-in accounts, optional OIDC, rate limits, quotas and starter/team/business entitlements.

Developer surface

OpenAPI HTTP API, typed Python SDK, SSE and WebSocket job streams, signed webhooks and an operator console.

Not available yet

  • Email verification and password recovery.
  • Self-serve account deletion.
  • Integrated payment checkout or subscription billing.
  • Verified live WhatsApp/iMessage provider delivery.
  • Verified multi-region or complete multi-instance operation.
The source repository's README and STATUS ledgers are the release authority when this page and a deployed binary disagree.
