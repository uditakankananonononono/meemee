GET STARTED

From zero to first conversation.

1. Create your account

Open the customer app. Enter your name, email and a password of at least 12 characters. Signup is built in; an external identity provider is optional.

2. Set your companion

Choose your timezone, then edit the persona name, tone, emoji preference and custom instructions. These settings condition replies and can be changed later.

3. Talk naturally

Start a conversation. Meemee keeps conversation history and can extract bounded useful facts into memory with provenance. Ask “What do you remember about me?” to inspect continuity.

4. Create an API key

Open Account & API keys. Name the key and choose only the scopes your integration needs. Copy the raw key immediately; Meemee stores only its digest and cannot show it again.

curl -H "Authorization: Bearer $MEEMEE_KEY" \
  https://your-meemee.example/v1/whoami

For operators

Use /console/ for jobs, tokens, quotas, audit and companion operations. Read OPERATIONS.md in the release archive before deploying. Set a strong vault key, trusted hosts and HTTPS; run preflight and the release audit.

Public signup defaults on. Set MEEMEE_SIGNUP_ENABLED=false when registration must be closed or handled only by OIDC.
