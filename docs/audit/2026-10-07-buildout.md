## SQLite migrations (historical item 28)

Three initial regression canaries failed against the original source: failed DDL
left a table, failed DML left changed data, and an embedded COMMIT published state
before a later failure. An expanded original-source run had seven failures,
including accepted transaction controls, disabled journal safety, and ledger edits.

The migrator now holds BEGIN IMMEDIATE across ledger read, SQL execution and ledger
publication. SQLite complete_statement separates statements without splitting
trigger bodies or literal semicolons. An authorizer rejects migration-controlled
transactions, savepoints, attached databases, PRAGMAs and ledger edits. Requested
migrations commit together; on failure their changes roll back. The metadata table
itself can still be initialized on a failed first run.

Targeted run: 16 passed (migration canaries plus existing operations/backup tests).
This proves local SQLite boundaries, not PostgreSQL migration safety, arbitrary
untrusted SQL containment, power-loss recovery or deployed migration rollout.
Migration authors must configure PRAGMAs outside migration scripts.

## Shell execution (historical item 10)

Two canaries failed against original source: an arbitrary workspace executable
named like an allowlisted program ran, and a 16 MiB output allocated about 33.6 MiB
before the reported cap applied. Programs are now bound to PATH-resolved executable
identities at configuration time; alternate same-basename paths are rejected.
stdout and stderr are concurrently drained with at most 200,000 retained bytes per
stream. On POSIX, timeout/cancellation kills the process group and reaps the child.
An intermediate timeout test also exposed Python 3.10's distinct asyncio.TimeoutError;
that intermediate failure was retained and corrected.

Targeted run: 23 passed (shell canaries and existing advanced/tool tests), including
both full pipes and a real child with inherited pipes. This is not command sandboxing:
an approved interpreter can run arbitrary code, tools can write outside the workspace,
operator PATH must be trusted, and descendants that create new sessions can escape a
process group. No Windows descendant-cleanup claim is made.

Original and intermediate failures, and final targeted outputs, are retained under
[evidence](evidence/). No live model/provider benchmark or production deployment was
performed. The current repository is public; local-first runtime privacy does not
mean its source repository is private.
